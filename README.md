# calendar_epaper

Googleカレンダーと連携し、最新の予定を自動表示するM5Paper専用のIoT電子ペーパーカレンダーです。紙のような目に優しい質感と、常に最新の予定が把握できるデジタルの利便性を両立しています。

## 特徴

* **Googleカレンダー自動同期**
  * サーバーサイドでGoogle Calendar APIから予定を取得し、デバイスに最新の状態を自動反映します。
* **電子ペーパーへの最適化**
  * 画面更新時の残像と操作ラグを抑えるため、画質優先モード（`epd_quality`）と高速描画モード（`epd_fast`）を動的に切り替えるロジックを実装しています。
* **省電力・通信最適化設計**
  * HTTPヘッダーの `ETag` を用いたキャッシュ検証機構を導入。サーバー側のカレンダー画像に変更がない場合は描画処理をスキップし、無駄な電力消費を防ぎます。
* **タッチ操作による直感的なUI**
  * 月間表示と週間表示の切り替え、過去・未来の月への遷移をタッチパネル操作で行えます。

## 技術スタック

### Client (Device)
* **ハードウェア**: M5Paper (ESP32)
* **言語**: C++ (Arduino)
* **主なライブラリ**: M5Unified, ArduinoJson, HTTPClient

### Server (Backend)
* **言語**: Python 3
* **フレームワーク**: FastAPI
* **外部API**: Google Calendar API

### Infrastructure
* **ミドルウェア**: Nginx
* **コンテナ**: Docker

## 構成

1. **M5Paper** がNTPサーバーから時刻を取得し、現在の表示モード（月/週）に応じたURLを生成。
2. **Nginx** 経由で **FastAPI** サーバーへHTTP GETリクエストを送信（前回取得時のETagを付与）。
3. サーバー側で **Google Calendar API** から予定を取得・画像化。
4. 画像に変更があれば新しい画像とETagを返し、M5Paperが画面を更新。変更がなければ 304 を返し、M5Paperは待機。
